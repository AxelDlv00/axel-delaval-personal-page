# Axel Delaval — Academic Website

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)
[![Website](https://img.shields.io/badge/Website-Live-blue.svg)](https://axeldlv00.github.io/axel-delaval-personal-page/)

A minimalist **multilingual academic portfolio**, built with **HTML, CSS, and vanilla JS**, showcasing my **education, research, and open-source projects**.  
Fully static and deployable on **GitHub Pages**.

---

## Structure

```

├── index.html                  # Main layout (navbar, sections, footer)
├── assets/
│   ├── css/                    # Stylesheets (theme, layout, components)
│   ├── js/                     # Scripts (dynamic rendering, language switch)
│   ├── fonts/                  # Font import (Inter)
│   ├── img/                    # Hero image and visuals
│   └── data/                   # Multilingual JSON files (en, fr, zh, it)
└── README.md

```

---

## Features
- **Dynamic language switching** (EN / FR / 中文 / IT)
- **Content-driven design** — all text in JSON
- **Reusable cards & tags** for research and projects
- **Dark / light theme** via `prefers-color-scheme`
- **100% static** — no frameworks or build tools

---

## Tech
- HTML5 + CSS3 + JavaScript (no dependencies)  
- Deployable directly via **GitHub Pages**
